## Git Workflow Critical Rule (Verified Feb 26)
**ALWAYS push after commit immediately:**
```bash
git add <files>
git commit -m "message"
git push origin main  ← DO NOT SKIP
```
Verify: `git status` shows "Your branch is up to date with 'origin/main'"

**Why:** Vercel doesn't redeploy without push. Saying "deployed" without push breaks trust.
